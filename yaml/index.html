    Yaml

    YAML yet antoher mark up language. It is human redable data serializatoin format it is used for configuring files and for data . It is easy to read and write. It used indentation and colons to structure the data., it is very important to have indentation two spaces> use #to write commands for descriptive text or hint, comments are ignored by YAML parser. key: value nested_key:

    • item 1

    • item 2 YAML uses below data structures.

    • - key: value represents simple values like string,numbers,booleans and null. scalars doesn't have indentation, so it can be expressed directly.

    For ex:

    string_key : 'String' numeber_key: 33 boolean_key: true null_key: null

    1. Lists lists are represented by - followed by space lists can contains any combination of scalars, other lists, or mappings(key-value) list_key:

    2. item 1

    3. item 2 sub_list:

    7. Mappings mapping represents key:value pairs use : to sepreate mappings can be neted within each other

    key: sub_key: value1 sub_key: 'value2'

    diff between list and mapping is list has - but map has key:value pair

    1. Multiline scalars if a scalar value spans into multiple lines use pipe | character to indicate a block scalar or > character to indicate folder scalar

    multiline_key: | This is a multi line scalar value

    NOTE : you can validate yaml syntax in yaml lint web , paste your code to validate. spaces are very important We can define multiple yml in single file with sepearation of ---, so --- will be treated as start of yml file
